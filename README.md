## Overview
This repository serves as a technical archive of laboratory coursework, engineering reports, and hardware prototyping projects. The documentation herein covers physical implementations and mathematical modeling across radio frequency (RF) engineering, digital signal processing, and semiconductor characterization.

## Directory Index

### 1. Communications and RF Engineering
* **`Microwave Lab/`** : S-parameter characterization, Vector Network Analyzer (VNA) measurements, and Ansys HFSS waveguide simulations.
* **`Analog Communication Lab/`** : Hardware implementation of AM/FM modulation, Voltage-Controlled Oscillators (VCOs), and active filter design.
* **`Digital Communication Lab/`** : BPSK, QPSK, Line Coding, and Delta Modulation hardware characterization.
