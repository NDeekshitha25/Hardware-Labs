# Core Electronics and Hardware Engineering Portfolio

**Author:** N Deekshitha  
**Institution:** Indian Institute of Technology (IIT) Kharagpur  
**Degree:** B.Tech (Hons.) in Electronics and Electrical Communication Engineering  

## Overview
This repository serves as a technical archive of laboratory coursework, engineering reports, and hardware prototyping projects. The documentation herein covers physical implementations and mathematical modeling across radio frequency (RF) engineering, digital signal processing, and semiconductor characterization.

## Directory Index

### 1. Communications and RF Engineering
* **`Microwave Lab/`** : S-parameter characterization, Vector Network Analyzer (VNA) measurements, and Ansys HFSS waveguide simulations.
* **`Analog Communication Lab/`** : Hardware implementation of AM/FM modulation, Voltage-Controlled Oscillators (VCOs), and active filter design.
* **`Digital Communication Lab/`** : BPSK, QPSK, Line Coding, and Delta Modulation hardware characterization.

### 2. Digital Systems and Signal Processing
* **`Digital Electronics Lab/`** : Custom RTL design (SystemVerilog), Finite State Machines (FSM), and FPGA deployment.
* **`Systems and Controls/`** : MATLAB modeling of Continuous Linear Quadratic Regulator (LQR) control, Kalman/Luenberger observers, and exact PBH stability tests.
* **`DSP Lab/`** : Digital Signal Processing, Parks-McClellan filter design, and DTMF spectral analysis.

### 3. Semiconductor Devices and Hardware Prototyping
* **`Analog Electronics Lab/`** : Design, biasing, and characterization of cascaded CE-CC amplifiers and IC active loads.
* **`Nano Electronics/`** : Academic literature review and research on single-electron transistors and heterostructure nanowires.
* **`Smart Water Telemetry Project/`** : Edge node telemetry system featuring LoRa SX1276 RF modules, 24-bit delta-sigma ADCs, and GSM-based cellular alerting.
