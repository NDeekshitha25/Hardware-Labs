# Smart Rural Water Distribution & Telemetry

### Texas Instruments | Design Thinking

**Project Overview:**
Developed a remote, solar-powered edge node telemetry system for rural water quality and distribution monitoring. 

**Key Technical Implementations:**
* **Sensors & Data Acquisition:** Interfaced precision optical turbidity, pH, and MEMS pressure sensors with 24-bit delta-sigma ADCs on remote solar-powered edge nodes.
* **RF Telemetry:** Implemented reliable LoRa SX1276 RF telemetry to Raspberry Pi SX1302 LoRaWAN gateways for distributed remote sensor communication.
* **Alerting System:** Integrated robust GSM SIM800L-based cellular emergency alerting algorithms directly into the remote hardware telemetry architecture.
